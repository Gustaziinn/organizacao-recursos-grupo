# Sistema de Organização de Recursos

Aplicação desenvolvida em *Java com Spring Boot* para facilitar a gestão e a alocação de recursos organizacionais, otimizando o acompanhamento de pedidos e o fluxo de trabalho.

---

## 🛠️ Tecnologias

* *Linguagem:* Java 17+
* *Framework:* Spring Boot
* *Gerenciamento de Dependências:* Maven
* *Qualidade de Código:* SonarQube
* *Controle de Versão:* Git & GitHub

---

## 📂 Estrutura do Projeto

* src/main/java — Código-fonte da aplicação (Controllers, Services e Repositories)
* src/main/resources — Configurações do projeto e arquivos de propriedades
* docs/ — Documentação técnica, requisitos e diagramas
* .github/ — Automações e pipelines de integração contínua (CI/CD)
